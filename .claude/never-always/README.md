# `.claude/never-always/` — Inviolable rules

These rules are absolute. They are **additive only**: append new rules
as needed, but do not soften or remove existing ones without explicit
discussion (and a `history/` entry recording the change).

Two files:

- [`never.md`](never.md) — things never to do, ever.
- [`always.md`](always.md) — things always to do, without exception.

Each rule has:

1. The rule itself (one sentence).
2. **Why:** the rationale (often a past incident or a strong reason).
3. **How to apply:** when/where the rule kicks in.

If you find yourself wanting to break a rule, that's a signal to *update
the rule with a noted exception*, not to silently bypass it.
