# `.claude/skills/` — Custom Skills

Currently empty. When a workflow repeats often enough to be worth
codifying as a Skill, add a `<skill-name>/SKILL.md` here.

See [Claude Code docs on Skills](https://docs.claude.com/en/docs/claude-code/skills)
for the format (frontmatter + body, invoked via `/skill-name` or
auto-triggered by description).
